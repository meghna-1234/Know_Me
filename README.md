## 🚀 Run Locally

### Prerequisites
- Node.js ≥ 18
- npm

### Steps

```bash
# 1. Clone the repository
git clone https://github.com/meghna-1234/Know_Me.git
cd Know_Me

# 2. Install dependencies
npm install

# 3. Start the dev server
npm run dev
```

The app will be live at **http://localhost:5173**

---

## 🌐 Deployment

This project is **automatically deployed** to [GitHub Pages](https://meghna-1234.github.io/Know_Me) using a GitHub Actions workflow (`.github/workflows/deploy.yml`).

Every push to the `main` branch triggers:
1. `npm ci` — install dependencies
2. `npm run build` — build the production bundle
3. Deploy the `dist/` folder to GitHub Pages

No manual steps needed. ✅
